# Code of conduct

Be decent. Concretely, in a repository about other people's wages:

* **Argue about the substance.** A disagreement over whether a payment is
  insurable is normal and useful. Make it about the rule and the source, not
  about the person who wrote the line.
* **Bring the source.** "This is wrong" is a start; "this is wrong, here is the
  provision and the issue of the State Gazette" is a contribution. Saying "I am
  not sure, but this looks off" is also welcome — uncertainty stated plainly is
  worth more than false confidence.
* **No real payroll data**, in issues, in pull requests, or in screenshots.
  Redact or generate a fixture. This is a hard line, not a preference.
* **Assume the maintainer is slow, not hostile.** This is a side project.

Harassment, personal attacks, and posting other people's data are not welcome and
will get a contribution closed. Persisting will get an account blocked from the
repository.

Report a problem privately through a
[security advisory](https://github.com/svedbg/trz/security/advisories/new) if it
involves someone's data, or open an issue otherwise.
